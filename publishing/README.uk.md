# Публікація постів

[English](README.md) · **Українська**

Воркфлоу n8n, який публікує мої пости в LinkedIn: черга в Google Sheets, чернетка в Telegram,
одне натискання «так» або «ні», далі публікація через API LinkedIn.
`workflow.json` це знеособлений експорт версії, що працює в проді (62 вузли).
Мої ID, креденшели й промпти замінено заглушками, тож без заповнення він нічого не робить.

## Шлях поста

1. **Розклад.** Будні о 09:00, резервні запуски об 11:00 і 13:00 за часовою зоною вашого n8n. Стандартна це Нью-Йорк, тож задайте `GENERIC_TIMEZONE` або змініть cron.
2. **Вибір.** Читає чергу. Спершу рядки з датою, що настала, і такий пост займає свій день. Інакше наступний рядок `ready` без дати.
3. **Бронь.** Рядок стає `pending`, щоб наступний запуск не взяв його вдруге.
4. **Текст.** Вирішує `type`: `raw` виходить як написано, `temat` і `projekt` пише Claude з вашої нотатки.
5. **Схвалення.** Чернетка з медіа приходить у Telegram з кнопками «так» і «ні». Очікування 20 годин.
6. **Публікація.** Текст, одне фото, галерея (тека на Drive), PDF-карусель або відео.
7. **Запис.** `done` з часом, фінальним текстом і лінком, або `skip` із повідомленням вам.

## Рішення у воркфлоу

- **Рядок без id заповнюється сам.** Перша версія мовчки відкидала такі рядки: шести запланованих постів для системи не існувало,
  а кожен запуск звітував про успіх. Вузол `Assign missing ids` прибирає причину.
- **Відмова не коштує дня.** `Backup guard` дає запускам 11:00 і 13:00 взяти наступний рядок після відмови.
  Якщо «ні» означає порожній слот, люди перестають його натискати.
- **Запуск після завислого `pending` працює.** Резервний запуск блокує лише `done` або `pending` за сьогодні.
- **Гроші в тексті дають попередження** у повідомленні на схвалення, бо хибне число найгірша помилка в опублікованому.
- **Дати приймаються в багатьох формах.** Нечитабельна дата відправляє рядок у звичайну чергу, він не губиться.

## Налаштування

Потрібні n8n і креденшели для Google Sheets, Google Drive, Telegram, LinkedIn OAuth2 та HTTP-заголовок
(`x-api-key` для Anthropic API).

1. Створіть Google Sheet з колонками з `queue.example.csv`.
2. У `workflow.json` замініть `YOUR_SHEET_ID`, `YOUR_TELEGRAM_CHAT_ID` і `YOUR_PERSON_ID` (ваш id учасника LinkedIn).
3. Імпортуйте файл у n8n і підключіть креденшели до вузлів, де стоїть `REPLACE_ME`.
4. Впишіть свій голос у вузол `System prompt`. Два промпти у вузлах `Claude` теж короткі заглушки.
5. Додайте один рядок `raw` зі `status` = `ready` і запустіть воркфлоу вручну.
6. Заголовки `LinkedIn-Version` закріплені на `202606`. LinkedIn прибирає старі версії, тож оновіть їх, коли виклики почнуть падати.

У налаштуваннях воркфлоу можна додати error workflow, щоб отримувати тривогу про збій. Мій це окремий воркфлоу з двох вузлів, що шле повідомлення в Telegram.

## Колонки черги

| Колонка | Значення |
|---|---|
| `id` | унікальний, заповнюється сам, якщо порожній |
| `type` | `raw`, `temat` або `projekt` |
| `content` | готовий текст, тема або нотатка проєкту |
| `scheduled_date` | необовʼязково, перше число це день |
| `status` | `ready`, `pending`, `done`, `skip`. Інші значення ігноруються |
| `posted_at` | ставить воркфлоу |
| `image` | лінк на Drive: файл або тека для галереї |
| `post_text` | фінальний текст |
| `post_url` | опублікований пост |
